# Student Management Dashboard

A responsive Student Management Dashboard built with HTML, CSS and JavaScript. It lets administrators log in, register students, manage courses, enter marks and generate student marksheets from one clean interface.

## Features

- Administrator login and registration
- Dashboard with student and course statistics
- Add, view and manage student records
- Course management
- Marks entry (internal and external) with total and grade
- Student marksheet generation
- Settings page with profile and password update
- Data stored in the browser using localStorage

## Technologies Used

- HTML5
- CSS3
- JavaScript
